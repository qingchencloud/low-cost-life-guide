# 贡献指南

这个项目收集的是“错误建议如何变成高代价”的复盘，不收集猎奇故事或可复现的坑人教程。

## 提交前检查

- [ ] 案例已经去标识化，不包含真实姓名、联系方式、订单号或密钥。
- [ ] 标题直接描述反模式，而不是用夸张的行动号召。
- [ ] 写清楚它为什么有吸引力，以及被忽略了哪一个前提。
- [ ] 区分事实、个人经验和推断。
- [ ] 至少有一个可追溯来源，或明确标记为 C 级经验案例。
- [ ] 写出停止条件、止损动作和更稳替代。
- [ ] 健康、金融、法律内容注明地区、时间和适用边界。
- [ ] 不包含账号入侵、诈骗、危险医疗、规避监管或伤害他人的具体执行参数。

## 提交方式

1. 复制 [`templates/case.md`](../templates/case.md)。
2. 在 `data/cases.json` 增加完整对象，并在 `book/` 对应章节补充可读版。
3. 运行 `python scripts/validate.py`。
4. 创建 Pull Request，标题格式：`case: <案例标题>`。
5. 在 PR 描述中写明来源、匿名化处理和需要复核的地方。

复杂或有争议的选题，先开 Issue 讨论，避免重复劳动。

## 审核优先级

- **高**：健康、金融、法律、隐私、未成年人和人身安全。
- **中**：劳动、合同、关系、声誉和重大消费。
- **普通**：工具、学习、流程和个人效率。

高优先级条目需要第二位维护者复核来源和措辞。个人经验可以作为线索，但不能伪装成统计结论。
