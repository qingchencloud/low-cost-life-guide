# 方法：如何判断一条建议“看起来划算，实际上很贵”

## 1. 先写目标，再写建议

同一句建议在不同目标、时间跨度和风险承受能力下，可能得到不同结果。案例先记录场景和目标，再判断被省略的前提。

我们优先回答四个问题：

- 当下到底获得了什么？
- 哪些成本被推迟、转移或隐藏了？
- 失败后能否回滚？
- 有什么更稳的替代路径？

## 2. 低性价比指数

```text
展示指数 = 隐藏成本 + 风险严重度 + 不可逆性 - 表面收益
```

数据源保留原始分项：

| 字段 | 范围 | 含义 |
| --- | --- | --- |
| `apparent_gain` | 0—5 | 眼前的省钱、速度、确定感或面子收益 |
| `cost` | 0—5 | 钱、时间、机会和声誉的综合隐藏成本 |
| `irreversibility_penalty` | 0—3 | 越晚停越难修复的程度 |
| `low_value_index` | 0—100 | 方便检索的展示排序值 |

指数用于编辑排序，不等于个人财务、健康或法律结论。同一指数的两个案例，具体损失可能完全不同。

## 3. 证据等级

- **A**：官方文件、监管机构材料、系统综述、权威指南或可复核的原始数据。
- **B**：高质量同行评审研究、较大样本研究或明确方法的调查。
- **C**：匿名复盘、个人经验、机制推断或仍需核实的材料。

C 级案例可以保留，因为经验本身能提供预警信号，但页面会明确提示它不是普遍统计结论。

## 4. 事实、推断、建议分栏

案例页面的顺序固定为：

1. **事实**：发生了什么，来源在哪里。
2. **推断**：为什么这个决策容易失败。
3. **止损**：现在可以停止什么、保留什么证据、联系谁。
4. **替代**：同一目标还有什么更稳的路径。

错误建议默认折叠，先展示风险摘要和何时停止，避免断章取义。

## 5. 复核清单

发布前至少检查：

- 标题没有把反面建议写成鼓励语气；
- 所有数字都有来源，或标记为经验估计；
- A/B 级来源链接可打开，C 级明确说明不确定性；
- 真实人物、公司、金额和地点已去标识；
- 健康、金融、法律条目注明适用地区和最后核实时间；
- 条目包含停止动作、证据保留方式或正式求助路径；
- 没有把危险或违法行为写成可直接复制的操作步骤。

## 6. 版本与争议

每条案例保留 `updated_at`。如果来源互相冲突，保留主要观点和限制条件，不用单一结论掩盖争议。需要长期追踪的条目可以在 `sources/` 中增加核实记录。
